# README 配图

以下四张原图由项目作者提供，原样保留。README统一使用标准Markdown图片语法；双端预览使用`platform-previews.png`，同时提供两张高清原图链接，避免预览器过滤HTML图片标签。

`preview-layout.html`是本地预览排版源，浏览器将两张截图按300像素等高、原始宽高比排列后截取为`platform-previews.png`。这仅用于README展示，未修改原始截图内容。由于等高排版已经保存在一张PNG内，在不同Markdown预览器缩放时两端仍然等高。

| 文件 | 内容 |
| --- | --- |
| `workbook-6th-edition.jpg` | 武汉理工大学出版社，王成刚、赵奇平主编《工程图学简明习题集》（第6版）封面 |
| `android-reader.jpg` | 图序 Android 版，P11-4 的绘图过程与阅读界面 |
| `windows-reader.png` | 图序 Windows 版，章页目录、绘图区与步骤导航 |
| `original-reader.png` | 原版软件在高分屏下的显示，保留完整窗口以展示固定绘图区和大片留白 |

封面、原版界面及截图中的书籍、课件内容保留各自权利，不属于源码 MIT 授权。解包后的完整题库与两端运行资源已另外纳入仓库，默认直接使用题库；`samples` 下的原创演示继续用于开发调试。
