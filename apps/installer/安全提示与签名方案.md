# Windows 安装权限与安全提示

查询日期：2026-11-03。

## 当前已完成

公开安装入口1.1.0.7的内嵌清单为 requireAdministrator，双击时由 Windows 请求管理员权限。阅读器本体仍为 asInvoker，不额外要求管理员权限。安装向导默认保持 %LocalAppData%\DrawingStudio，不自动更换目录。已静态读取两份 EXE 的真实 PE 清单核对。

外层入口负责权限请求，内部 Inno 保留当前用户安装模式，避免把 AppData 安装变成面向所有用户的系统安装。Inno 官方说明：非管理安装模式也能使用进程已有的管理员权限。[安装模式说明](https://jrsoftware.org/ishelp/topic_admininstallmode.htm)

工具宿主当前不是管理员，尚未执行 Windows 安全桌面的 UAC 确认和提权后的实际安装。不能仅凭内嵌清单正确就声称写入问题全部解决。

## “Windows 已保护你的电脑／未知发布者”

这是先前用户确认的提示类型。SmartScreen参考文件及发布者信誉；代码签名有助于显示可信发布者及延续信誉，新签名文件仍可能提醒。自签证书无法解决公开用户的默认信任，EV证书也不再具有首次运行免提醒保证。[微软信誉机制](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)

管理员权限负责权限请求，代码签名负责可验证的发布者身份；申请管理员权限不会让一个未签名文件变成受信任发布者。本机当前用户证书库没有可用、带私钥且未过期的代码签名证书，交付EXE仍为NotSigned。

## 可行的发布方案

| 方案 | 前提及限制 |
| --- | --- |
| 继续分发独立EXE，使用受信任CA代码签名 | 需取得签名身份，为发布程序、安装器签名，保持一致发布者；新版本仍可能需要积累信誉。 |
| Microsoft Store 的MSIX渠道 | 经商店认证后由微软处理包签名。现有EXE直接交商店不等于免费重签；MSI/EXE渠道仍要求发布者自行签名。 |
| SignPath Foundation免费开源签名 | 需满足开源、维护、发布和构建管线等条件，当前项目及题库是否符合尚未核对。没有提交项目或申请。 |
| Azure Artifact Signing | 有身份和地域限制；官方目前对个人开发者限美国、加拿大，不能默认适用于所有地区个人。 |

来源：[微软签名选项](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options)、[SignPath申请条件](https://signpath.org/terms.html)、[Azure身份与地域条件](https://learn.microsoft.com/en-gb/azure/artifact-signing/quickstart)。

对本项目，独立EXE发行需要取得受信任签名身份；若以后满足完整开源条件，可研究SignPath。没有购买证书、创建收费订阅、上传程序或公开题库。

## 如果出现明确病毒名称

Defender给出具体威胁名称属于另一类检测，可向微软提交样本申诉。[微软文件分析入口](https://www.microsoft.com/en-us/wdsi/filesubmission)

普通消费者SmartScreen的“未知应用”信誉没有手动提交就能立刻获信任的通道。它与明确恶意检测的误报申诉不能混为一项。本次未提交文件，也未更改系统防护。
