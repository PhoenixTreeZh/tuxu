# 解包后的题目与答案

适用于武汉理工大学出版社、王成刚与赵奇平主编的《工程图学简明习题集》（第6版）。本目录保留 Windows 阅读器所需的数据，Android 的对应数据位于 `apps/android/app/src/main/assets/content`。

- 207 个可见题目入口，按章节和页码检索。
- 1316 个绘图场景，保留步骤、答案分支及图内点击关系。
- 14 段模型动画、6 个视频；保留 Windows 所需的源文件和兼容副本，Android 提供对应的兼容媒体。
- Windows 保留 WMF、几何与文字指令及原始位图图层；Android 保留由同一来源导出的 SVG 路径。

`windows/library.json` 是原生绘图库，`windows/index` 是轻量目录与逐题文档，`windows/media`、`frames`、`animations`、`videos` 是配套资源。`video-compatibility.json` 保存旧 AVI 与 Windows 兼容视频的映射，重新生成索引时仍可保留播放路径。

这些文件是现有解包、整理结果，不需要运行旧 EXE 才能读取。原稿已有的空图链接和其他缺失说明保留，不将其当成已修复；数据完整性检查不等于学科答案审校。
